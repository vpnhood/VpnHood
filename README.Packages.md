# VpnHood!

This package is part of [VpnHood](https://github.com/vpnhood/VpnHood), an open-source VPN written
from scratch in C# to get past advanced firewalls and deep packet inspection. Its libraries are
published as NuGet packages, so you can build your own VPN app or server on them. The `VpnHood.Net`
packages are general networking libraries that any .NET app can use.

## Use one version for every VpnHood package

The VpnHood packages are built and released together under one version number, and their APIs
change from release to release. Reference all of them at the same version.
