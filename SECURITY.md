# Security policy

VpnHood is a VPN, so a security problem in it can put its users at risk. Thank you for reporting one.

## Report a vulnerability

Report it privately, never in a public issue or discussion:

- On GitHub: [report a vulnerability](https://github.com/vpnhood/VpnHood/security/advisories/new). Only the
  maintainers see it.
- By email: [support@vpnhood.com](mailto:support@vpnhood.com), with "Security" in the subject.

Say what is affected (an app and its platform, VpnHood! SERVER, a NuGet package), its version, and how to reproduce
the problem. We reply to every report, keep you informed while we work on it, and credit you in the advisory if you
wish.

## Supported versions

Security fixes go into the latest release of the apps, VpnHood! SERVER and the NuGet packages. Check that the latest
release still has the problem before you report it.

## Audit

Include Security audited VpnHood for the Open Technology Fund's Red Team Lab:
[the report](https://www.opentech.fund/security-safety-audits/vpnhood-security-audit-results/) and
[what it means for you](https://www.vpnhood.com/security-audit/).
